## Решения развилок (конструкция, на утверждение)

1. **Сигнальная полоса** сверху: дефицит машин по дням (спрос−свободно),
   незакрытая сетка по клиентам (будущие дни), освобождающиеся машины.
   Порог «освобождается много» — живой: p80 дневных освобождений за
   35 суток из trips, кламп 2–8 (без зашитой «4»). Клик по сигналу —
   фокус на день/зону.
2. **Решение в ячейке**: клик по ячейке зоны×дня — разбор спроса
   (заявки без ТС поимённо + дыры сетки) и кандидаты matchVehicles
   на каждую заявку; действия «✏ в черновик» и «Назначить сейчас»
   (штатный assign, права trips:write). Клик по 🆓 машины — «чем
   занять»: заявки без ТС и дыры сетки, отсортированы по ₽.
3. **Дыра сетки** закрывается только через создание заявки (штатная
   «заявка из плана», orders:write) — пакетный book-week не годится
   для одного слота. В черновике шаг «бронь» и шаг «назначение»
   раздельны: бронь создаёт заявку, назначение — на существующую.
4. **Черновик «что если» (Э5)** — локальный у пользователя (state),
   баланс пересчитывается поверх серверного (клиентская дельта);
   «Применить» выполняет пункты последовательно штатными вызовами
   и показывает отчёт ✓/✗ по каждому. Ничего массового без явного
   списка пунктов (принцип «человек решает»).
5. **Разворот зоны**: плечи клиентов (факт/план с готовностью) +
   машины зоны с полосками занятости по дням (рейс/ремонт/без
   водителя/пересменка/🆓/✏черновик) и бейджем круга 🎡 — как в
   прототипе руководителя.
6. **ТВ-режим 📺**: внутри вкладки (полноэкранные карточки баланса по
   дням + сигналы). Вынос на физическое табло (board) — отдельное
   решение при переносе.
7. **Э4 (вывод старых вкладок)**: на переходный период старые вкладки
   получают плашку-ссылку «переезжает в Производственный график»;
   уникальные операции там живут до переноса их аналогов (правка
   сетки слотов, круги, регулятор баланса). Скрытие вкладок — отдельное
   решение руководителя после обкатки.
8. **Деньги**: как в Э1 — показ только при money=full (клиентский гейт,
   канон существующих вкладок); серверный гейт денег — вопрос к общей
   ревизии, не здесь.

## Чек-лист живых нормативов (самопроверка)

- Новые числа в diff: порог «освобождается» — p80 из факта с клампом
  2–8 (кламп = коридор здравого смысла, как dock_max_km 150–500);
  лимиты отображения (6 сигналов, 12 машин в списке) — вместимость
  UI, не бизнес-пороги. Других констант нет.
- Время/км/деньги — только через matchVehicles/transitHours/
  plannedKmBetween/ставки слотов. Своих формул нет.
- Дрейф: /api/prografik пишет в ответ поле norms (порог освобождений,
  образцов) — видно в интерфейсе; при переносе добавить строку в
  «📐 Нормативы недели».
- Эффект при переносе мерить: доля заявок, назначенных из графика
  (audit assign), и скорость закрытия дефицитов (дни с need>free).
