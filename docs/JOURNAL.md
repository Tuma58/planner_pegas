  через перерисовку ЖИВЫМ узлом — значение, каретка и обработчики

  Это закрывает и тихое автообновление, и onReload после действий, и
  фильтры. Дополнительно: тик не стартует при зажатой кнопке мыши
  (протяжки кисти/ганта/выделений святы) и перепроверяет ввод ПОСЛЕ
  скачивания снимка (10 МБ качается секунды); attachSearch применяет
  только последний из асинхронных ответов (устаревший список больше
  не перетирает свежий). Проверено: force-refresh посреди набора в
  поиске Ресурса — узел тот же, «комаров» цел, фокус на месте.

- График: ввод перестроен по-Excel (решение руководителя «кисть
  неудобна»): сначала выделение дней — клик, протяжка прямоугольником
  по нескольким строкам, Shift-клик расширяет, Ctrl-клик добавляет,
  Esc снимает — затем клик по коду применяет его ко всему выделению;
  режим-кисть и кнопка «Залить выбранным строкам» упразднены (заливка
  «галочки строк + с/по» тоже делается кликом по коду). Попутно
  вылечены ДВЕ потери данных, унаследованные из прототипа: (1) занятый
  синхронизацией обмен молча глотал сохранение, а поздний ответ
  предыдущего обмена откатывал свежие правки старой серверной версией —
  теперь отложенный вызов дожимается, изменённые в полёте экипажи не
  затираются ответом, отправленное фиксируется по снимку; (2) выделение
  держалось на индексах строк живой таблицы — фоновый обмен пересобирал
  её, и код мог лечь чужим строкам; ключи переведены на стабильные
  «водитель+слой+дата». Инструкция «Как пользоваться» на странице
  обновлена.
