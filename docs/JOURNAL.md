# Журнал изменений PegasLogistic v1

Каждое изменение проекта — строкой: дата, суть, хэш коммита.
Новые записи сверху. Ведётся с 12.09.2026 (правило в CLAUDE.md);
более ранняя история — в git log и памяти ассистента.

## 2026-09-12

- Ревизия транзита по парку (команда руководителя): распределение
  план/формула по 138 активным — 73 в ±15%, 14 длиннее в окно клиента
  (законно), 18 хвостов старых медиан → режим sanitizeInflatedTransit
  (revision): разовое сжатие до честного расчёта с выигрышем от 2 ч,
  метка transit_revision_2026_09_12.

- Транзит: дорога плеча училась от отметки «на линию» — вбирала подгон,
  очередь и погрузку (Аустрина→Пермская: 28,3 ч при честных 15,8, ворота
  погрузки считались дважды). Теперь интервал «убытие с погрузки →
  прибытие на выгрузку», фолбэк «на линию».
- Километры плеча: порог 20 ч и эксклюзивные дни оставлены только
  календарному фолбэку — рейсы с честным одометром идут в медиану без
  них (было 3 образца при 19 одометрах).

- Сборщик честного одометра: очередь застревала на первых 120 безнадёжных
  кандидатах (Пилот не отдаёт данные за интервал; за сутки +1 рейс) —
  метка gps_km_tried_at, пробованные откладываются на 2 суток, дорога
  достаётся несканированным (~412 в очереди).
- Документация: созданы docs/CONTEXT.md (живой контекст) и этот журнал;
  правило «каждый 5-й коммит — ревизия документации» в CLAUDE.md.
- Карта переведена на собственный тайл-сервер `/tiles/` (tileserver-gl +
  russia.mbtiles 9,9 ГБ из OSM-экстракта; nginx-кэш 30 дн) после
  блокировки tile.openstreetmap.org — 3985299.
- Служба маршрута мака: маршрут 100.100.10.0/24 живёт только при
  активном офисном VPN, шлюз 192.168.89.170 — 1822295, aeea29f.
- Telegram: исходящие Bot API заблокированы провайдерами с ~08.09;
  добавлен релей через app_meta telegram_api_host + воркер
  tools/telegram-relay-worker.js — 739c4ef (ждёт воркер руководителя).
