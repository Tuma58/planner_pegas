# Проект «Живая себестоимость» (Э5 учёта затрат)

Статус: ПРОЕКТ, не реализуется (решение руководителя 03.11: «проектируем,
но не делаем — в фоновом режиме; дальше учимся получать все затраты»).
Реализация — после слова «делаем», когда журнал наполнится статьями.

## Идея

Сегодня переменная себестоимость — рукой заданная настройка
(`variableCostPerKm()`: ₽/км + страховка-дороги + водитель на суточный
пробег), на ней стоят сегменты клиентов, маржа и подбор. Журнал затрат
начал копить ФАКТ. Живая себестоимость — это выученное из журнала
значение рядом с настройкой: система сообщает дрейф, человек правит
цель (автоматика рекомендует — человек решает, п. 6 концепции).

## Конструкция (по концепции живых нормативов)

1. **Факт переменных ₽/км парка**: сумма без-НДС записей variable-статей
   журнала за окно / километры парка за то же окно (канон — журнал
   одометров, как в «Пробегах»). Окно — последние ПОЛНЫЕ календарные
   месяцы (счета живут месяцами: ЗП, лизинг, Платон приходят пачкой);
   скользящая медиана по 3 месяцам, когда накопятся.
2. **Факт постоянных ₽/машино-день**: сумма fixed-статей / календарные
   машино-дни парка периода — против `leasePerVehicleDay +
   overheadPerVehicleDay`.
3. **Ворота доверия — покрытие журнала.** Пока статьи наполнены не все,
   сравнение с настройкой ЛЖЁТ в сторону «затраты ниже норматива».
   Мера покрытия: отношение факта журнала к нормативной оценке того же
   периода (км × настройка). Пока покрытие ниже порога — норматив
   живёт в режиме «копим факт, сравнивать рано», никаких подсказок
   «снизьте калькуляцию». Порог — настройка руководителя (цель),
   стартовое предложение 70%.
4. **Кламп**: выученное значение принимается в коридоре 0,5–1,5 от
   настройки калькуляции; вне коридора — работает прежнее, расхождение
   видно в логе (п. 3 концепции).
5. **Дрейф виден**: строка в «🧠 Живых нормативах» (покрытие, live
   против настройки, по месяцам) и в «📐 Нормативы недели»; при полном
   покрытии и расхождении свыше ~10% — подсказка «обновите калькуляцию»
   (как уже сделано для суточного пробега).
6. **Потребители НЕ переключаются сами.** Сегменты, маржа, подбор —
   по-прежнему через `variableCostPerKm()` из настройки; живое значение
   — советник рядом. Автоподстановка в настройку — только отдельным
   решением руководителя (кнопка «принять live-значение»).
7. **Разрезы на вырост**: ₽/км по типам сцепок и по бортам (плитка
   карточки ТС уже считает борт) — сравнение машин между собой, ранняя
   диагностика «дорогого» борта.

## Решения перед стартом (к слову «делаем»)

- Порог покрытия (70%?) и окно (3 полных месяца?).
- Какие статьи считаем обязательными для «полного покрытия» переменных:
  минимум — топливо + дороги/Платон + ремонт/запчасти/шины.
- Включать ли штрафы в переменные ₽/км (искажают км-норматив, но
  являются затратой) — предлагаю считать отдельной строкой вне ₽/км.

## Карта «получаем все затраты» (рабочая линия сейчас)

Статьи целевого P&L «Направление СТ» → источник факта:

| Статья | Источник | Состояние |
|---|---|---|
| ГСМ (топливо) | топливный процессинг (API/выгрузка ЛК) | СЛЕДУЮЩИЙ: ждём название и доступы |
| Мойка, стоянка | Dornet | ✅ едет само |
| Шиномонтаж | Dornet | ✅ едет само |
| Эвакуация ТС | Dornet | ✅ едет само |
| Штрафы | Dornet (оплаченные) | ✅ едет само |
| Ремонт (работы) | Dornet СТО + внешние СТО счетами | частично; внешние — импорт Excel |
| Запчасти | счета поставщиков; КАНДИДАТ: суммы в заказ-нарядах ремзоны с автозаписью в журнал | импорт Excel / доработка ремзоны |
| Автошины | счета поставщиков | импорт Excel |
| Автодор | ЛК «Автодор — Платные Дороги» (выгрузка/API) | кандидат на коннектор |
| Платон | ЛК Платон (выгрузка/API) | кандидат на коннектор |
| Пропуск, ГЛОНАСС | счета помесячно | ручной ввод / импорт 1С |
| ЗП водителей + налоги | 1С (выгрузка помесячно) | пока норматив калькуляции |
| Лизинг, страхование, налоги, накладные | 1С помесячно | пока норматив |
| Расходы направления (АТП, зарплаты отделов, связь, ПО…) | 1С помесячно | пока норматив; статьи заводятся в справочнике по мере надобности |

Принцип: у каждой статьи — самый дешёвый надёжный путь: API-кабинет >
регулярная выгрузка Excel (формат учим один раз) > ручной ввод
помесячно. Дедуп и привязка к бортам — уже общие для всех путей.
