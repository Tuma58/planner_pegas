# Telegram-бот планера: настройка и управление

Бот: **@pegas_planer_bot**. Шлёт уведомления планера в Telegram на телефон.
Первоисточник всегда лента планера — бот лишь дублирует на телефон.

## Три уровня управления

**1. BotFather (владелец бота — руководитель).** Диалог с @BotFather в Telegram:
- `/newbot` — создать бота (сделано);
- `/mybots` → выбрать бота → меню управления:
  - **API Token → Revoke** — перевыпустить токен (если утёк: старый гаснет,
    новый вставить в планер);
  - **Edit Name / Description / About / Botpic** — имя, описание, аватар
    (чисто витрина, на работу не влияет);
  - **Delete Bot** — удалить насовсем (рассылка остановится).

**2. Планер (админ).** Настройки → «🔔 Telegram-уведомления»:
- **Токен** — единственное обязательное поле; вставили → бот работает,
  убрали → канал выключен (кнопка «🔔» у сотрудников исчезает);
- **Имя бота** — для ссылки привязки; можно не заполнять: планер сам
  спросит у Telegram настоящий username и сохранит.

**3. Сотрудник (каждый сам).** Кнопка «🔔» в шапке планера:
- не привязан → код и ссылка на бота: перейти, нажать Start — готово,
  код живёт 15 минут;
- привязан → выбор режима и отвязка. Команды боту: `/stop` — отвязаться,
  `/start КОД` — привязаться заново (код берётся кнопкой «🔔»).

## Что и кому приходит

Режим у каждого сотрудника свой (по умолчанию «только аварии»):
- **«Только аварии»**: 🚨 простои под погрузкой/выгрузкой, ⚖ узкие дни
  баланса парк↔сетка, невыход машины в окно погрузки;
- **«Все уведомления»**: плюс вся лента конвейера СВОЕЙ роли (у логиста —
  логистовое, у продаж — продажное) и общие рассылки (утренний отчёт дня).

Руководителю при привязке сразу приходит последний «📆 Отчёт дня».

## Типовые ситуации

- **Не приходят уведомления**: проверить режим (кнопка «🔔»), не отправлял
  ли человек `/stop`; крайний случай — привязаться заново.
- **Сменил телефон/аккаунт**: `/stop` со старого (или «Отвязать» в планере),
  привязка заново с нового.
- **Сотрудник уволен**: деактивация учётки в планере автоматически
  выключает его из рассылки (шлём только активным).
- **Токен утёк** (переслали, показали на экране): BotFather → Revoke →
  новый токен в Настройки. Сотрудников перепривязывать НЕ нужно.
- **Бот «молчит» на сообщения**: так и задумано — он понимает только
  `/start КОД` и `/stop`, остальное игнорирует. Писать ему бесполезно,
  вопросы — в чат планера.

## Технические заметки (для истории)

- Отправка и приём — прямой HTTPS к api.telegram.org с принудительным IPv4
  (у LXC нет IPv6-маршрута, DNS хостера отдаёт битые адреса; рабочий IP
  закреплён в compose.yaml → extra_hosts);
- опрос бота раз в 20 секунд (вебхук невозможен: самоподписанный сертификат);
- сообщения длиннее ~3900 символов обрезаются;
- токен наружу не отдаётся (в bootstrap только признак «настроен» и имя).
