# 11. Перенос в планер по отделам (план, 10.11.2026)

Решение руководителя 10.11: переносить по отделам в таком порядке:
1. **ТОиР** — самый безопасный: сейчас под ним в планере никто не работает.
2. **Эксплуатация.**
3. **Логистика.**
4. **Штаб.**

До начала переноса руководитель вручную проверяет сотрудников в справочнике лаборатории.

## Как это ложится на код

Лаборатория отличается от планера на 57 коммитов: 149 файлов, около 21,7 тыс.
строк. Изменения в основном общие — каркас, общие экраны и служебные модули:
- оформление «Пегас-Авто»;
- навигатор по структуре;
- наборы ролей (access);
- АРМ;
- структура и выдача доступа;
- правки server.mjs, app.js, styles.css, guide.js.

Поэтому код **по отделам не режется** — разрезанный каркас был бы рискованнее
целого.

Делить можно включение. Права по наборам действуют только у сотрудника, которому
набор назначен (`accessOf`). Без набора сотрудник остаётся в прежней модели:
- прежние права;
- всё направление;
- прежний стартовый экран.

Отсюда схема:

> **Код выкладывается один раз; отдел включается назначением наборов его
> людям.** Откат отдела — снять наборы и вернуть прежние права. Код при этом
> не откатывается.

## Что увидят все с первого дня (до включения своего отдела)

- **Новое оформление и навигатор по структуре.** Экраны те же, видимость прежняя.
- **Утренняя рассылка 07:00** — одна вместо двух.
- **Новые экраны, на которые хватает прежних прав:** Структура, Цели и задачи и
  др. Они только для чтения, не мешают.
- **Центральный рубеж записи для учёток с режимом «только просмотр».** На проде
  этот режим уже есть; рубеж только делает запрет записи сплошным.

Объявить заранее — плакатом на табло / в Вестнике.
