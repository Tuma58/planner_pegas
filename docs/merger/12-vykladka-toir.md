## Порядок выкладки

1. **Объявление** (табло / Вестник): «С [дата] новое оформление планера и меню
   по структуре. Экраны и права у всех прежние. ТОиР получает свои рабочие места».
2. **Копия прод-базы** перед выкладкой — делает руководитель.
3. **Код:** после вашего «выкладываем» я заливаю `perenos` в main перемоткой.
   Пересборку выполняет руководитель:
   ```
   ssh -4 root@91.144.178.239 'cd /opt/pegas-planner && git pull --ff-only && docker compose up -d --build && sleep 8 && curl -s http://127.0.0.1:3000/api/health'
   ```
4. **Проверка после выкладки:**
   - вход;
   - у логистов всё по-старому;
   - новое оформление.
5. **Включение ТОиР:** ⚙ Настройки → «Перенос по отделам» → ТОиР.
   - Сверить таблицу «кто кем станет»: Тарасов Е найден.
   - Нажать «Включить отдел».
6. **Доступ:** «Сотрудники» → «🔐 Выдать доступ · N» → «🖨 Печать листков».
   - Листки получают люди ТОиР с ролью: механики, операторы, старшие смены,
     мастера, снабжение.
   - У Тарасова прежний пароль, листок ему не нужен.
7. **Утро после:**
   - все ли вошли и сменили временный пароль (плитка «Вход»);
   - открывается ли у каждого рабочее место;
   - нет ли заявок «не вижу».

   Если что-то пошло не так — «Откатить отдел»: код остаётся, права
   возвращаются.
