# 14. Включение Штаба (подготовлено 11.11.2026)

Руководитель 11.11: «Готовим Штаб». По порядку перед ним шла Логистика, и она
пока не включена. Штаб от неё не зависит: включать можно в любом порядке.

У всех шестерых учёток на проде нет. Включение создаёт их в справочнике, рабочие
места открываются. Действующих учёток включение не трогает.

## Что решить руководителю

1. **Руководитель направления.** В табеле его нет, должность в структуре пуста.
   Сейчас это учётка «Администратор». Вероятный кандидат на проде — «Сальников ОВ»
   (роль руководителя): ему можно назначить набор «Руководитель направления» в
   карточке, должность — «Руководитель направления СТ».
2. **Учётки вне табеля:** «Артём Сальников», «Табаев Ф», «Иванов П» (гость).
   Включение отделов их не трогает — живут по-старому. Варианты для каждой:
   - оставить как есть;
   - назначить должность и набор;
   - уволить.
3. **Охрана: вход общий или личный?** Листки будут на четверых. Если пост
   КПП работает с одного компьютера, удобнее один общий вход поста.

## Порядок

Новая пересборка для Штаба не нужна — код и снимок штата уже в main.

1. ⚙ Настройки → «Перенос по отделам» → Штаб → сверить → «Включить отдел».
2. «Сотрудники» → «🔐 Выдать доступ» → листки или «📋 Скопировать все».
3. Утром — вход и рабочие места. Откат — «Откатить отдел».
